# Hold’em table art brief

Saved project asset: `src/main/resources/art/holdem-table.png`.
Tool: built-in imagegen, new-image generation mode, opaque background, no reference images. Generated specifically for the open-source dui-demo. The PNG is original artwork; the runtime raster conversion does not add it to the resource pack. The UI overlays dynamic controls/cards/chips; the illustration deliberately contains none of those elements.

## Exact prompt

> Use case: stylized-concept. Asset type: production background artwork for an actual playable Texas Hold'em game UI inside Minecraft, not a screenshot mockup. Primary request: a particularly beautiful fresh, original poker table background, polished indie-game illustration, warm cinematic casino elegance with playful contemporary taste. Composition: wide landscape 16:9, strict overhead orthographic view, an elongated oval deep petrol green/teal felt poker table centered, thick rounded aubergine leather padded rail with brass/gold edge trim, subtle stitching and tactile highlights, four restrained brass seat markers around the table, dark ink navy surroundings with extremely subtle botanical/art-deco corner embellishments. Keep the center 65 percent of the felt spacious and empty so dynamic playing cards, pot totals and labels can be overlaid later. Leave a calm dark horizontal area at the bottom for controls and top for UI title. Materials: richly illustrated velvet felt, soft leather, warm gold edges, elegant lighting, gorgeous legible silhouette, intentional premium composition, clean enough to downsample to pixel-game resolution. Palette: dark navy #111B29, petrol #164C4A, mint #7DE5C4, warm champagne gold #E9BE70, small coral #F57D83 details. Constraints: NO text, NO letters, NO numbers, NO playing cards, NO loose chips, NO currency symbols, NO people, NO logos, NO watermark. Original artwork; do not imitate any named artist or specific existing casino product. Landscape image fills the entire frame, no white margins.
